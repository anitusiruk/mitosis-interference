# Research Question

A distribution shift does not necessarily require new model capacity.

We test whether predicted destructive interference is a better signal
for dynamic adapter expansion than distribution novelty.

For incoming window W and existing adapter A_j:

N_j(W) = novelty relative to adapter j's historical distribution.
I_j(W) = predicted damage caused by adapting adapter j to W.

Hypothesis:

Adapter expansion should occur only when no existing adapter can
safely absorb the incoming information.

Initial experiments must test the signal before implementing expansion.
