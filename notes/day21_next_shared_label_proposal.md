# Proposal: a learnability-gated natural same-label extension

This document is a proposal, not a preregistered confirmation study or executed experiment. The existing MultiNLI 64-token/1440-example stress results remain visible and are not replaced.

A useful extension should separate allocation behavior from failure to learn the task. Retain the natural three-label fiction/government/telephone shifts, premise-grouped splitting, true sentence-pair tokenization, recurrence without repeated examples and full output space. Increase the context and training exposure in a bounded single-learner development pilot. Candidate settings include 256-token context and 5760 incoming examples; these numbers are proposed rather than frozen. Time a small prefix first on the actual 4090, project the complete cost and decline any job predicted to last hours.

Use a fixed single-package learner to test learnability before any adaptive method comparison. Evaluate the untrained checkpoint and each fixed segment-end checkpoint on a train-derived development holdout. Keep premise groups intact across fit, development and future confirmation data; audit normalized-premise overlap and retained class counts. Record tokenizer/model/dataset revisions, sample hashes, truncation fractions, exact updates, example exposures, batch size, clipping, dropout, AdamW recipe and peak memory. No official held-out test split is used for pilot choices.

Select any training recipe with an equal-budget declared learning-rate grid on pilot seeds only. Freeze the grid, selection metric, tie rule, admissible compute, stopping rule and a meaningful above-chance learning threshold before running that pilot. A threshold cannot be chosen after seeing the pilot accuracy. Do not select a favorable genre, order, prediction rule or adaptive method from observed confirmation outcomes. Avoid using a fixed learning threshold to imply population significance.

Once the pilot passes its predefined gate, write a separate executable confirmation specification. Use fresh training seeds with both orders paired within seed, the full LoRA learner, zero-LoRA classifier-only control and frozen-hidden-pre-classifier control. If factorial compute is affordable, retain all sixteen intervention cells and both folds on all eligible mature batches, with the same bitwise observer gate. Track allocation sequences, deferred batches, incoming updates, exposure, full-space loss, label-balanced and concept-level accuracy, temporal retention, every declared deployment rule and distinct resource costs. Retain failed and timed-out runs. Summarize at the seed level; repeated checkpoints and examples are not independent replicates.

The stronger study succeeds scientifically even if it shows a narrower or null mechanism. It should determine whether the original attribution survives meaningful same-label learning, rather than tune toward a desired acceptance narrative.
