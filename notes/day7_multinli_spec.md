# Third-regime development protocol, declared before outcomes

Use the author dataset `nyu-mll/multi_nli`, **train split only**. Official matched/mismatched validation and test material remains untouched. The dataset is a three-class premise/hypothesis entailment task across genres (author description: https://cims.nyu.edu/~sbowman/multinli/; dataset fields: https://huggingface.co/datasets/nyu-mll/multi_nli/blob/main/README.md).

Genres are A=fiction, B=government, C=telephone. All share labels entailment, neutral and contradiction; filter label -1. Partition development by SHA256 of normalized premise text modulo 10 equaling zero. Every hypothesis sharing that premise remains in the same partition, preventing premise-level leakage. Within each genre choose a fixed balanced development subset of 64 examples per class using seed 424242. Training chooses disjoint 96-per-class subsets per occurrence; A and B recur twice, C appears once. Thus each segment has 288 examples and the five-segment stream contains 90 batches of 16. No repeated training pair IDs.

Represent each input as a genuine tokenizer text/text_pair pair, with longest-first truncation at 64 tokens, matching the frozen short-context budget of the existing system. All learners receive identical paired tokenization. This small short-context training protocol is a development stress test, not a claim to competitive MultiNLI performance. Stronger training and length sensitivity will be needed if this regime becomes a main-paper benchmark.

Compare private LoRA-and-head CAU-v1, zero-LoRA head-only CAU-v1, fixed single LoRA-and-head and fixed single head-only. Keep the exact frozen controller and AdamW settings from Day 5. Reservoirs remain 512 per adapter; no fixed-total-resource claim. Evaluate all three predeclared label-free routers and keep oracle values explicitly separate.

Run seeds 2026 (development pilot), 2027 and 2028, each with two boundary conditions. Sharp: A1 B1 A2 C1 B2. Blurry: at each boundary replace the last four preceding batches and first four following batches with eight mixed batches whose newer-genre counts are 1,3,5,7,9,11,13,15 of 16. Shuffle each mixed batch with a fixed seed. Preserve every original example and label exactly once. Per-example genre annotations and dominant segment names are evaluation metadata only. The learner sees only text pairs and labels. Check train/development premise separation, no duplicate source pairs, balanced totals and sharp/blurry multisets before live runs.

This is an exploratory transfer of a method developed on other regimes. Three seeds do not establish broad genre-order robustness; do not pool sharp/blurry windows as independent samples. No changes based on outcomes. Queue follows the frozen Day-6 batch on the same GPU and honors the 03:20 launch/03:25 checkpoint cutoffs on 2026-10-06. Preserve failures, incompletion and low learning accuracy explicitly.
